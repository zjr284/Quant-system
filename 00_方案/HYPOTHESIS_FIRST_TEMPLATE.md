# Hypothesis First 策略假设模板

开始编码或调参前填写。每个策略假设单独建档并编号；若假设、数据或执行规则改变，创建新版本。

## 1. 可检验条件

- 假设编号与版本：
- 适用市场、标的与周期：
- 仅使用在决策时已经可见的数据：
- 明确的入场、退出与持仓规则：

## 2. 为什么可能有效

- 可能存在的市场机制：
- 预计可捕获的收益来源：
- 交易频率与容量预期：

## 3. 如何证伪

- 主要零假设或基准策略：
- 训练、验证、留出区间及切分日期：
- 计入手续费、点差、滑点、冲击和未成交的方式：
- 失败判据（净收益、回撤、风险调整收益、换手等）：
- 多重试验与数据窥探的校正方法：

## 4. 预期影响

- 若假设成立，预期观察到的结果：
- 相对基准的最小有意义改善：
- 对仓位、流动性与组合风险的影响：

## 5. 可能失败的原因

- 可能的结构变化或市场状态：
- 数据质量、幸存者偏差、前视偏差风险：
- 执行、费用、延迟及流动性风险：
- 失败时的处理和停止条件：

## 研究冻结与审批

- 数据集版本 / 哈希：
- 代码提交 / 哈希：
- 参数文件 / 哈希：
- 预先登记日期：
- 研究负责人：
- 审核结论与批准人：
